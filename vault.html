    What “secret” means here

    Encrypted before it leaves the tab.

    01 / encryption

    AES-256-GCM

    The key comes from your pass phrase through PBKDF2-SHA256 with 210,000 rounds. Only the cipher text is stored — never the VINs, never the phrase.

    02 / storage

    Two places, both yours

    The cipher text is mirrored to your account in Supabase, so a second device you sign in on finds the locked vault already there. The same blob sits in this browser under cardna.vault, and the file you download is that same cipher text. All three need the pass phrase to open.

    03 / honest limits

    As strong as the phrase

    This is a browser vault, not a password manager. A short or reused pass phrase is the weak link, and anyone using your unlocked device can read an open vault.

    No recovery. If you lose the pass phrase, the VINs cannot be decrypted — not by us, not by anyone. Keep an encrypted file copy somewhere safe, and keep the phrase somewhere that is not the same place. A plain-text export is offered for convenience, and it is exactly that: unencrypted.
    What the vault does. The cipher text is mirrored to your account in Supabase, so the locked blob is there on any other device you sign in on, and it stays unreadable without the pass phrase — we never see the list or the phrase. Clearing site data no longer means re-importing a file, though the downloaded file is still the copy that outlives the account.
