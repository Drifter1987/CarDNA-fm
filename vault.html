    What “secret” means here

    Encrypted in the tab, never uploaded.

    01 / encryption

    AES-256-GCM

    The key comes from your pass phrase through PBKDF2-SHA256 with 210,000 rounds. Only the cipher text is stored — never the VINs, never the phrase.

    02 / storage

    Two places, both yours

    The encrypted copy sits in this browser under cardna.vault, and the file you download is the same cipher text. Both need the pass phrase to open.

    03 / honest limits

    As strong as the phrase

    This is a browser vault, not a password manager. A short or reused pass phrase is the weak link, and anyone using your unlocked device can read an open vault.

    No recovery. If you lose the pass phrase, the VINs cannot be decrypted — not by us, not by anyone. Keep an encrypted file copy somewhere safe, and keep the phrase somewhere that is not the same place. A plain-text export is offered for convenience, and it is exactly that: unencrypted.
    Coming with accounts. A server-side copy that only you can read — Postgres with row-level security, rather than a file only this browser knows about — is designed but not live yet, so today this page and your downloaded file are the only copies.
